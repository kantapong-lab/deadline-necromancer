# Deadline Necromancer — คู่มือ Event Card ทั้ง 15 ใบ

การ์ดเหตุการณ์ประจำวัน (**Event Card**) จะถูกสุ่มเปิด 1 ใบในช่วง **Morning Stand-up** ของวัน **อังคาร–ศุกร์** (วันจันทร์ไม่เปิด เพราะเป็น Grace Period) ไม่เปิดซ้ำในเกมเดียวกัน เพื่อสร้างสถานการณ์ไม่คาดฝันเหมือนลูกค้าที่ชอบสร้างเรื่องให้ทีมโดยไม่รู้ตัว

---

## กติกาพื้นฐานปัจจุบัน (ที่ Event Card อ้างอิง)

* **Kickoff:** หลอด Mana เริ่มเกมที่ 1 หน่วย
* **ผ่านคืน = Mana +1 ทันที:** ทีมปั่นงานพื้นฐานให้อัตโนมัติ ไม่มีแอ็กชัน "ปั่นงาน" ให้เลือกแล้ว
* **ทุกคนต้องใช้สกิลทุกคืน:** เว้นได้เฉพาะสกิล 1 ครั้ง/เกม (Chrono, DevOps) ที่เก็บไว้ได้ หรือสกิลที่ใช้ไม่ได้แล้ว ส่วนการ์ด **#11** และ **#13** จะเปลี่ยนเงื่อนไขนี้ชั่วคราว
* **ฝ่ายมืด** ใช้สกิล **และ** เลือกแอ็กชันก่อกวน 1 อย่าง: ส่งงานหลอก (0) / วางบั๊ก (−1 Mana) / สาป Burnout
* **วางบั๊ก:** หักได้สูงสุด **−1 ต่อคืน** (แม้หลายคนวางพร้อมกัน) เว้นแต่การ์ดระบุไว้
* **โทษ Skip (Meeting Overrun):** ถ้าโหวตแล้วไม่มีใครถูกไล่ออก ปั่นงานพื้นฐานคืนนั้นได้ **+0** และถ้าเกิดซ้ำติดกัน 2 รอบขึ้นไปได้ **−1**
* **ไล่ฝ่ายมืดออกได้ Mana +2**
* **เป้าหมาย Mana:** `ManaMax = floor(N/2)` (8 คน = 4 หน่วย)
* **Mana ปรับได้ 0 – เป้าหมาย** เสมอ

---

## ประเภทของ Event Card

* **Instant Effect (ส่งผลทันที):** ปรับค่าหลอด Mana Task ทันทีที่เปิดการ์ด
* **Night Rule (กติกาพิเศษคืนนี้):** เปลี่ยนเงื่อนไขการใช้สกิลหรือผลลัพธ์ของคืนที่ตามมา 1 คืน
* **Daily Rule (กติกาพิเศษประจำวัน):** เปลี่ยนเงื่อนไขของเฟสพูดคุย โหวต หรือประกาศข้อมูลสาธารณะ
* **Choice Event (รับ / ปฏิเสธ):** ผู้เล่นที่ยังอยู่ทุกคนโหวตตอนเช้าว่าจะ **"รับ"** หรือ **"ปฏิเสธ"** ใช้เสียงข้างมาก **เสมอกัน = ปฏิเสธ** ต้องตัดสินให้เสร็จก่อนเข้าเฟสโหวตไล่ออก

| :--- | :--- | :--- | :--- | :--- |
| **01** | **ลูกค้าอนุมัติเร็ว** | `FAST APPROVAL` | Instant | หลอด **Mana +1** ทันที |

| **07** | **ลูกค้าขอตรวจ Log** | `LOG AUDIT` | Night Rule | สกิล **Code Review** (`Senior Dev`) ได้รับ Log เพิ่มอีก 1 คนแบบสุ่มในคืนนี้ |

| **15** | **ลุ้นโบนัสกลางปี** | `BONUS TEASE` | Choice | **รับ:** คืนนี้ปั่นงานพื้นฐานได้ **+2** แต่หากมีฝ่ายมืดวางบั๊กสำเร็จแม้แต่ 1 คน หลอดจะโดนหัก **−2** ทันที (หักคงที่ ไม่ว่ากี่คน) / **ปฏิเสธ:** ไม่เปลี่ยนแปลง |

## หมายเหตุการใช้งาน

* **ลำดับการคำนวณ Mana ในคืนที่มีการ์ด:** ปั่นงานพื้นฐาน (+1, ปรับตามการ์ด/โทษ Skip) → หักบั๊ก → ตรวจเงื่อนไขชนะ
* **Hotfix Rollback (Chrono)** ยกเลิกบั๊กและคำสาปตามปกติ รวมถึงโทษ −2 ของการ์ด #15
* **Deploy on Friday (DevOps)** ใช้ร่วมกับการ์ด #03 / #09 ได้ ผลไม่ซ้อนกัน (บาเรียและฮีลใช้ไม่ได้อยู่แล้ว)
* **การ์ด #13 (รับ)** ใช้ทับกติกา "ต้องใช้สกิลทุกคืน" ชั่วคราว และ **#11** เปิดให้ทุกคนพักได้เป็นกรณีพิเศษ
* **ฝ่ายมืดบอท** โหวต "รับ" ทุก Choice Event เพราะความเสี่ยงที่ฝ่ายแสงต้องแบก
